# Objektinis_egzaminas
## Apie programa
Si programa realizuoja tris teksto analizes uzduotis naudojant C++ OOP ir STL konteinerius. Programa leidzia:
Suskaiciuoti kiek kartu pasikartoja kiekvienas zodis tekste. 
Sugeneruoti cross-reference lentele, nurodancia kuriuose sakiniuose pamineti pasikartojantys zodziai.
Surasti ir isvesti visus URL adresus tekste.

## Naudotos technologijos
C++
CMake
Google test
STL konteineriai(map, set)
WiX Toolset(MSI diegimo paketo kurimui)
